## Deployment

1. Create a GitHub repository.

2. Upload all project files.

3. Go to

Settings

Pages

4. Select

Deploy from Branch

5. Choose

main branch

/root

6. Save.

GitHub will generate your website.

---

## Important

GitHub Pages is static hosting.

To actually receive assignments, connect the form with:

- Google Forms
- Formspree
- Netlify Forms
- Firebase
- Supabase
- PHP Server
